# 回归测试

在项目根目录运行 `uv run pytest -q`。默认测试使用模拟模型，不调用收费 API。

覆盖分阶段模块加载、HTTP 会话与实时事件、停止/重连/导出、工具循环、三种观察模式、长文件原子编辑和本机命令执行。Shell 测试会在临时目录运行短命令，并检查超时和取消清理。

`support/cua_verifier.py` 仅供可选桌面验收脚本独立读取目标状态；不作为产品模式，也不放进学生发布包。旧的 `test_reference.py` 验证第二课所带的 Agent 标准实现。

第一课教学骨架由 `test_lesson_one_scaffold.py` 验证：只补四个辅助函数仍不能接管对话，必须完成自己的 run_turn；检查器拒绝提前返回、漏写工具结果和超出轮数等循环错误。未完成步骤立即提示，停止信号继续向外传递。面向学生的逐步检查位于 `lesson_01_agent/check.py`，使用假模型和假工具。

`test_learning_edit.py` 验证先接入 Edit 的流程：初始 TODO 不开放工具；学生完成声明与分发后，实际调用保存的分发函数。临时课程中通过 HTTP 聊天调用真实编辑器，完成辅助函数和 Loop，再由新保存的学生循环接管并自检。模型回复固定，文件读写与源码加载真实执行；另检查版本冲突、批量拒绝、路径限制、语法拒绝和原始字节备份。接入检查器位于 `lesson_01_agent/check_edit.py`。

`test_learning_chat.py` 验证预置教学 Chat 的列目录/读文件、文件访问边界、检查缓存/语法错误/超时，以及保存完整源码后真正执行学生 `run_turn()` 并自检，再改坏时回到教学 Chat；使用临时课程副本和假模型，不修改作业文件。

`test_clear_conversation.py` 验证批量清理历史会话：保留当前对话上下文及运行中任务、历史只读会话的保留、清理后重启不恢复、CSRF 和无效请求校验、文件移动失败时整批回滚。

`test_fixed_experiments.py` 验证固定实验会话：两个课时仅预置长文件编辑、移除实验拒绝访问与历史隐藏、清理保护、提示词预填、重置消息与模型上下文、运行记录归档、重启恢复、重新执行、模型设置限制及 CSRF / 运行中保护。

`test_session_persistence.py` 验证普通会话多轮后重启仍只有一个入口、工具请求/结果与模型元数据恢复、再次重启继续归组、同名独立会话不合并、按会话清理全部轮次，以及中断上下文隔离、旧版只读记录保留、截图与密钥处理、保存失败时原记录不受损。

通用 HTTP/SSE 测试使用 `support/model_io.py` 替换模型与工具 IO，实际运行生产 Agent 流程。应用本身没有免密钥演示模式，测试替身不打包给学生。

`test_single_step_chat.py` 验证教学 Chat 每次只请求一次模型、批量工具与错误结果暂停、继续不追加用户消息、补充要求接着处理结果、重复/过期继续请求拒绝、取消、接口测试隔离，以及重启后恢复等待状态。Edit 集成测试逐次继续完成真实编辑，随后验证学生 Loop 自动接管。

`test_runtime_recovery.py` 验证事件契约检查、运行异常回退有效历史、诊断跨重启恢复、工具结果保留且不自动重试、旧错误事件兼容，以及工具执行异常作为错误结果返回模型。
# 三阶段教学与提供的输入输出支持

`test_lesson_io.py` 验证框架不会自动推进循环、批量图片位于所有工具结果之后、错误事件完整，以及一次汇总循环检查失败。`test_learning_edit.py` 在临时课程中验证一次编辑返回自动检查，下一轮直接解释结果或由学生 Loop 接管，没有额外检查请求。课程副本保留消息准备和 `lesson_io`，只恢复学生填写区。

`test_edit_conversation.py` 使用临时学生 Agent 与真实编辑工具，验证跨轮撤销、重启恢复历史和文件、失败后保留已写入内容，以及显式重置后恢复基线。
